# Prism Mission & Vision

## Mission Statement

**GitHub as an OS for any business — no coding required.**

## The Vision

Lower the barrier so that anyone — not just developers — can store their business knowledge in GitHub Markdown files, and have an elegant, AI-powered way to create, maintain, and interact with those documents.

You shouldn't have to be a developer to live on GitHub.

## The Problem We're Solving

GitHub is the definitive platform for software development, but its complexity and developer-centric design make it inaccessible to non-technical business users. This creates a critical knowledge silo:

- Business knowledge lives in Notion, Google Docs, Confluence, Slack
- Technical knowledge lives in GitHub
- The two are disconnected, causing sync issues and inefficiency
- Companies can't use GitHub as a true "single source of truth"

## Our Approach

Prism is **not** a GitHub replacement. We're the essential UX layer that brings the entire business into the GitHub ecosystem.

We abstract away the complexity — no "git", no "repos", no "commits" — and expose only the value: AI-powered search, elegant authoring, governed publishing.

## Core Principles

1. **True data ownership** — Users' data lives in their own GitHub repos, in an open format, forever
2. **No vendor lock-in** — We're a layer, not a trap
3. **On-ramp, not off-ramp** — We bring people TO GitHub, not away from it
4. **Speed to value** — From signup to first answer in under 2 minutes
5. **Accessible to everyone** — No jargon, no intimidation, just usefulness

## Success Looks Like

- Non-technical founders and operators running their business on GitHub
- Technical and non-technical teams unified in one knowledge base
- Companies choosing open, durable Markdown over proprietary formats
- GitHub becoming the OS for knowledge work, not just code
